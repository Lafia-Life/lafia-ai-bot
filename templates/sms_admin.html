SMS Integration Guide

For rural Uganda users:

  1. Users send SMS to your shortcode/phone number
  2. Questions are automatically processed by AI
  3. Responses sent back via SMS (auto-split if long)
  4. No internet required for users

Supported phone formats:

  • +000000000 (International)
  • 0701234567 (Local Uganda)
  • 701234567 (Without prefix)

Setup Requirements:

  • Africa's Talking account with SMS credits
  • API key configured in environment
  • Webhook URL set in Africa's Talking dashboard
  • HTTPS certificate for production webhook
